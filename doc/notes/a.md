### 多条指令使用

* **无条件顺序执行:**`cmd1; cmd2`
* **上条命令成功时执行下条命令:**`cmd1 && cmd2`
* **上条命令失败时执行下条命令:**`cmd1 || cmd2`
* **后台执行该命令:**`cmd &`
* **上一条命令的输出作为下一条命令的输入:**`cmd1 | cmd2`

### 文件描述符和重定向

| 文件描述符 | 含义         |
| ---------- | ------------ |
| 0          | 标准输入     |
| 1          | 标准输出     |
| 2          | 标准错误输出 |

| 命令                    | 说明                                                                                  |
| ----------------------- | ------------------------------------------------------------------------------------- |
| `command > file`      | 将输出重定向到 `file`。                                                             |
| `command < file`      | 将输入重定向到 `file`。                                                             |
| `command >> file`     | 将输出以**追加** 的方式重定向到 `file`。                                      |
| `n > file`            | 将文件描述符为 `n` 的文件重定向到 `file`。                                        |
| `n >> file`           | 将文件描述符为 `n` 的文件以**追加** 的方式重定向到 `file`。                 |
| `n >& m`              | 将输出文件 `m` 和 `n` **合并** 。                                           |
| `n <& m`              | 将输入文件 `m` 和 `n` **合并**                                              |
| `<< tag`              | 将开始标记 `tag` 和结束标记 `tag` 之间的内容作为输入（**here document**）。 |
| `command1 \| command2` | 将命令1的输出作为命令2的输入（**管道**）。                                      |

### 通配

* `?` 用于匹配**一个**字符，`*` 用于匹配**任意个**字符。
* `{}` 当你有一系列的指令，其中包含一段公共子串时，可以用花括号来自动展开这些命令。

```Bash
convert image.{png,jpg}
# 会展开为
convert image.png image.jpg

cp /path/to/project/{foo,bar,baz}.sh /newpath
# 会展开为
cp /path/to/project/foo.sh /path/to/project/bar.sh /path/to/project/baz.sh /newpath

# 也可以结合通配使用
mv *{.py,.sh} folder
# 会移动所有 *.py 和 *.sh 文件

mkdir foo bar

# 下面命令会创建 foo/a, foo/b, ... foo/h, bar/a, bar/b, ... bar/h 这些文件
touch {foo,bar}/{a..h}
```

## 文件操作相关

```Bash
xrags [options] [command] 
```

该命令用于将**标准输入**转换为命令 `command` 的参数，常配合 `|` 使用。

```Bash
tee [OPTIONS] [FILE] 
```

该命令用于将**标准输入**的数据写到多个文件或者标准输出，常配合 `|` 使用。

`OPTIONS=-a` 时表示追加。

```Bash
find 指定目录 -name '*.ext'
```

该命令用于查找文件，也可以对查找到的命令进行批量处理，平替命令为 `fd`，用 `tldr find` 查看更多示例。

```Bash
grep "模式字符串" 路径/到/文件
```

该命令用于查找文件中匹配字符串的内容，常用选项如下:

* `-C N` 打印匹配字符串的**上下各 N 行**的内容
* `-R` 表示**递归**查找目录下所有文本
* `-v` 表示输出**不匹配**的内容，表示反选

## 程序安装命令

* **安装 tar.bz2 包**

<!-- end list -->

```Bash
tar -jxvf example-1.2.3-1.tar.bz2
```

* `-j` 使用`bzip2` 解压`.bz2` 格式压缩包
* `-x` 表示解压，解压`.tar` 格式压缩包
* `-v` 在终端显示详细信息
* `-f` 指定文件名，这里指`example-1.2.3-1.tar.bz2`

解压后的文件可能为安装好的程序，创建桌面快捷方式后即可使用；也可能为源码，需要进行构建安装才能使用。

* **安装 ** **deb**** 包**

<!-- end list -->

```Bash
sudo dpkg -i example-1.2.3-1.deb
```

`deb` 包只能在 `su` 环境下进行安装，除了使用 `-i` 进行安装外，还可以使用 `-l` 进行查询，使用 `-e` 进行卸载。

* **安装 tar.gz 包**

<!-- end list -->

```Bash
tar -xzvf example-1.2.3-1.tar.gz
```

* `-z` 使用`gzip` 解压`.gz` 格式压缩包

其他选项含义同 `tar.bz2`。

解压得到的内容也同 `tar.bz2`。
