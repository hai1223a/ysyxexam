== CPU架构图
* 使用标准五级流水线设计, 包括取指, 译码, 执行, 访存, 写回. +
* 取指若命中cache, 延迟为3个周期; 若未命中cache或者未使用cache, 延迟周期未知. +
* 译码, 执行, 写回一个周期即可完成. +
* 访存若未使用则占用一个周期, 若使用则延迟周期未知. +
* 目前添加了ICACHE, 使用前递技术解决数据冒险, 使用分支预测解决结构冒险, 使用阻塞技术解决其他问题, 所有的异常均传递到写回阶段进行处理.
