== CPU架构图
* 使用标准五级流水线设计, 包括取指, 译码, 执行, 访存, 写回. +
* 取指若命中cache, 延迟为3个周期; 若未命中cache或者未使用cache, 延迟周期未知. +
* 译码, 执行, 写回一个周期即可完成. +
* 访存若未使用则占用一个周期, 若使用则延迟周期未知. +
* 目前添加了ICACHE, 使用前递技术解决数据冒险, 使用分支预测解决结构冒险, 使用阻塞技术解决其他问题, 所有的异常均传递到写回阶段进行处理.

=== 操作数统计
`lui` 仅将 `imm` 写回 +
`ecall` 将 `pc` 写入 `mepc`, 将 `异常号` 写入 `mcause`, 将 `mtvec` 读出作为跳转地址 +
`ebreak` 终止仿真, 类似 `nop` 指令在流水线中传递, 在写回阶段才终止程序 +
`mret` 将 `mepc` 读出作为跳转指令

* **ALU**

`op1` 为 `rs1` 的指令: `addi`,`slti`,`sltiu`,`andi`,`ori`,`xori`,`slli`,`srli`,`srai`,`add`,`slt`,`sltu`,`and`,`or`,`xor`,`sll`,`srl`,
`sub`,`sra`,`beq`,`bne`,`blt`,`bltu`,`bge`,`bgeu`,`lw`,`lh`,`lhu`,`lb`,`lbu`,`sw`,`sh`,`sb`

`op1` 为 `pc` 的指令: `auipc`,`jal`,`jalr`

`op2` 为 `rs2` 的指令: `add`,`slt`,`sltu`,`and`,`or`,`xor`,`sll`,`srl`,`sub`,`sra`,`beq`,`bne`,`blt`,`bltu`,`bge`,`bgeu`

`op2` 为 `imm` 的指令: `addi`,`slti`,`sltiu`,`andi`,`ori`,`xori`,`slli`,`srli`,`srai`,`auipc`,`lw`,`lh`,`lhu`,`lb`,`lbu`,`sw`,`sh`,`sb`

`op2` 为 `4` 的指令: `jal`,`jalr`

* **BQU**

`op1` 为 `pc` 的指令: `jal`,`beq`,`bne`,`blt`,`bltu`,`bge`,`bgeu`

`op1` 为 `rs1` 的指令: `jalr`

`op2` 为 `imm` 的指令: `jal`,`jalr`,`beq`,`bne`,`blt`,`bltu`,`bge`,`bgeu`

|===
| 信号 | 来源/去向 | 含义

* ALU : 该模块的主要用于 *算数指令的执行*;  *条件跳转指令的条件判断*;  *无条件跳转指令返回地址的计算*;  *访存指令访存地址的计算*;  
* BQU : 该模块例化了一个32位加法器, 用于 *条件跳转指令的跳转地址计算*;  *无条件跳转指令跳转地址计算*
