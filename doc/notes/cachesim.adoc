== 功能
该模拟器仅仅模拟 `ICACHE` 的命中率, 即输入真实程序的PC值, 判断是否命中ICACHE, 并在未命中时替换掉ICACHE中对应的内容. 下层介质为 `SDRAM` , 该介质地址与大小由变量 `sdram_addr` 与 `sdram_len` 记录.

== 使用方式
程序的调用格式如下：

[source,shell]
----
$ ./program <压缩文件路径> <OFFSET BITS> <INDEX BITS> <NUM OF WAYS> <MODE OF REPLACE>
----

参数说明：

[cols="1,4", options="header"]
|===
| 参数 | 说明

| `argv[1]` | 压缩文件路径
| `argv[2]` | OFFSET 位数
| `argv[3]` | INDEX 位数
| `argv[4]` | 组相联路数（NUM OF WAYS）
| `argv[5]` | 替换策略模式  
  * `0` → 不考虑VALID的RANDOM  
  * `1` → 考虑VALID的RANDOM  
  * `2` → LRU
|===

== 脚本使用方式
程序的输入文件格式为 `.bin.bz2` , 输出格式为 

[source,shell]
----
$ 总数量 521336 命中数量 394716 命中率0.757124 TMT 1772680
----

=== Shell
`collect.sh` 为自动化测试脚本, 测试变量设置例子如下:

[source,shell]
----
DEFAULT_INPUT="source/microbench-train.bin.bz2"
offsets=(2 3 4)
indexes=(1 2 3 4 5 6)
ways=(1 2 4 8)
modes=(0) # 0 RealRandom, 1 random, 2 LRU
----
